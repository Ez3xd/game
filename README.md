Aero-Liminal: The 2.5D Idle Experience
Un juego incremental colaborativo donde los espacios liminales vacíos evolucionan hacia una utopía nostálgica, combinando interfaces retro, elementos de cristal y una atmósfera inmersiva.

🌌 Sobre el Proyecto
Aero-Liminal es un idle game diseñado para mezclar mecánicas adictivas de progresión matemática con una dirección de arte única. El jugador comienza en un entorno 3D de baja fidelidad visual y, mediante la acumulación de recursos, introduce elementos 2D que transforman el espacio hacia estéticas inspiradas en el Frutiger Aero y el Vaporwave. El objetivo es automatizar la generación de energía mientras se disfruta de una evolución visual y sonora constante.

🎮 Bucle de Jugabilidad
El flujo principal del juego es infinito y se divide en tres fases clave para asegurar la retención del jugador:

Generación Activa (El Clic): El usuario interactúa con un objeto central (como un disco de vinilo retro) para generar "Ondas" manualmente.

Automatización: Las Ondas se invierten en la compra de sprites 2D que se instancian dinámicamente en el entorno tridimensional, generando recursos por segundo de forma pasiva.

Reinicio (Prestigio): Al alcanzar un límite de progresión, el jugador puede "formatear el sistema", obteniendo multiplicadores permanentes de memoria y desbloqueando paletas de colores completamente nuevas para la sala.

🛠️ Tecnologías y Arquitectura
Para facilitar el trabajo en equipo y mantener un desarrollo ágil y bien estructurado, el proyecto se apoya en las siguientes herramientas:

Motor Principal: Desarrollo basado en Godot Engine utilizando GDScript para manejar la lógica de nodos, temporizadores y la renderización de elementos 2D con efecto Billboard dentro del entorno 3D.

Alternativa Web: Estructura adaptable para integrarse con TypeScript y React si se decide portar la interfaz de usuario a un entorno de navegador en el futuro.

Control de Versiones: Repositorio centralizado para coordinar las ramas de desarrollo, revisión de código y aportes de todos los compañeros.

Gestión de IA: Integración progresiva de módulos de código generados mediante prompts estructurados para acelerar la creación del bucle matemático.
